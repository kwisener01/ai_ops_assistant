## Overview

### Purpose
This document defines the key performance indicators (KPIs) tracked at daily, weekly, and monthly intervals to monitor operational performance and drive continuous improvement.

### KPI Framework
All KPIs follow SMART criteria:
- **Specific**: Clearly defined metric
- **Measurable**: Quantifiable with data
- **Achievable**: Realistic targets
- **Relevant**: Aligned to strategic goals
- **Time-bound**: Specific measurement frequency

### KPI Categories
- **Leading Indicators**: Predictive measures (what will happen)
- **Lagging Indicators**: Historical measures (what has happened)
- **Strategic KPIs**: Long-term goals (annual)
- **Operational KPIs**: Short-term performance (daily/weekly/monthly)


**MTBF Example:**
```
Equipment operated 2,000 hours in the month
3 failures occurred
MTBF = 2,000 / 3 = 667 hours
```

**MTTR Example:**
```
5 repairs totaling 8 hours
MTTR = 8 hours / 5 repairs = 1.6 hours
```

## AI Operations Assistant Integration

### Automated Data Collection
The AI Operations Assistant system automatically:
- Collects issue data from all departments
- Categorizes by type, severity, and department
- Tracks resolution time and status
- Identifies recurring patterns

### Root Cause Analysis Tracking
- All quality issues and downtime incidents analyzed using 5-Whys

## Appendix: KPI Definitions and Formulas

### Overall Equipment Effectiveness (OEE)
```
OEE = Availability × Performance × Quality

Availability = (Operating Time / Planned Production Time) × 100
  where Operating Time = Planned Production Time - Downtime

Performance = (Actual Output / Theoretical Output) × 100
  where Theoretical Output = Operating Time × Ideal Cycle Time

Quality = (Good Units / Total Units Produced) × 100
```

**Example:**
- Shift: 8 hours (480 minutes) planned production
- Breaks: 30 minutes (not production time)
- Downtime: 50 minutes
- Operating time: 480 - 30 - 50 = 400 minutes
- Ideal cycle time: 1 minute/unit
- Actual production: 350 units
- Good units: 340 units

```
Availability = 400 / 450 × 100 = 88.9%
Performance = 350 / 400 × 100 = 87.5%
Quality = 340 / 350 × 100 = 97.1%
OEE = 88.9% × 87.5% × 97.1% = 75.5%
```

### Process Capability (Cpk)
```
Cp = (USL - LSL) / (6σ)
Cpk = min[(USL - μ) / (3σ), (μ - LSL) / (3σ)]

where:
  USL = Upper Specification Limit
  LSL = Lower Specification Limit
  μ = Process Mean
  σ = Process Standard Deviation
```

**Interpretation:**
- Cpk ≥ 2.0: Excellent (6 Sigma level)
- Cpk ≥ 1.67: Capable (desired target)
- Cpk = 1.33 - 1.67: Acceptable
- Cpk < 1.33: Not capable, improvement required

### Inventory Turnover
```
Inventory Turnover = Cost of Goods Sold (Annual) / Average Inventory Value

Average Inventory Value = (Beginning Inventory + Ending Inventory) / 2

Days of Inventory = 365 / Inventory Turnover
```

**Example:**
- Annual COGS: $12,000,000
- Average inventory: $2,000,000
- Turns = $12M / $2M = 6 turns per year
- Days = 365 / 6 = 61 days of inventory
